# Role contracts

Loaded **on demand by role**, not by directory. See the root [`AGENTS.md`](../../AGENTS.md).

| Contract | Read it when |
|---|---|
| [code-reviewer.md](code-reviewer.md) | You are reviewing any change, anywhere |
| [platform.md](platform.md) | You are touching CI/CD, packaging, or GitHub rulesets |

Reviewer, Platform and Coordinator **never auto-load**. Wearing one of those hats without opening its contract
is the usual way this family gets a repo wrong.
